# @trebired/utils

Shared Trebired utility helpers.

The package exposes shared helpers from the root import:

```ts
import {
  clonePlain,
  readEnvFile,
  readPackageJson,
  readProductIdentity,
  slugText,
  toObject,
  toString,
} from "@trebired/utils";
```

## Exports

- `@trebired/utils`: pure value, env, package metadata, product identity, and version helpers.
